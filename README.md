# Biker Companion

A responsive web app for tracking motorcycle trips, expenses, and ride statistics.

## Features

- Calculate total trip expenses
- Calculate cost per kilometer
- Save trips
- Edit saved trips
- Delete trips
- Reset trip details
- View total trips
- View total distance
- View total expenses
- View average cost per kilometer
- Store trips using browser localStorage
- Responsive design for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Project Structure

Biker-Companion/

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a browser.
3. Start tracking your trips.
